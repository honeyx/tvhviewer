# Notice

TVHviewer is a fork of [TVHplayer](https://github.com/mfat/tvhplayer),
originally created by **mFat**.

All credit for the original application architecture, TVHeadend
integration, and core functionality belongs to mFat and the TVHplayer
contributors. This fork builds on that foundation with:

- A redesigned dark/light color theme system
- A redesigned menu bar, icon toolbar, and status bar (video/audio
  format info, tuner signal strength)
- A full program-guide EPG grid covering all channels at once, with
  both a timeline view and a newspaper-style column view, instead of
  the original's one-dialog-per-channel EPG lookup
- Favorites menu, separate from the full channel list
- Various bug fixes (fullscreen toggle, local recording save dialog,
  icon loading, volume slider, etc.)
